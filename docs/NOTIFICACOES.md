# Mensagens do Carretos Studio (Telegram @carretos_studio_bot e email)

Todas as mensagens do Telegram começam por "📣 Carretos Studio · ". Os emails têm assunto "Carretos Studio · …".
As rotinas a horas fixas usam a hora de Lisboa e nunca se repetem no mesmo dia (mesmo que o agendador reinicie).

| Mensagem | Quando | Canal |
|---|---|---|
| 📲 Hora de publicar em … (legenda + ficheiros + link "Publicar à mão") | À hora marcada, para contas em modo assistido: Facebook pessoal, página LinkedIn (até à aprovação) e o que a TikTok recusar | Telegram |
| Legenda para o TikTok (+ link "Publicar à mão") | À hora marcada, quando um vídeo vai para os rascunhos da app TikTok | Telegram + email |
| ♪ Rascunho enviado para o TikTok | À hora marcada, quando um carrossel/foto vai para os rascunhos (já leva a legenda) | Telegram |
| ✅ Publicado em … (com link) | Quando uma publicação sai sozinha (Instagram, Facebook Página, LinkedIn) | Telegram |
| ⚠️ Falhou a publicação #… | Na hora, quando uma publicação falha | Telegram |
| Ligações com problemas | 08:30, verificação diária; só quando uma ligação passa a falhar (uma vez) | Telegram + email + aviso no dashboard |
| 📝 Por aprovar nas próximas 24h | 09:00, só se houver publicações com data nas próximas 24 h por aprovar | Telegram |
| Ligações a renovar | 09:00, a 14, 7, 3 e 1 dia(s) antes e no dia em que expira (depois: todos os dias) | Telegram + aviso no dashboard |
| 🗓 Resumo semanal | Segunda-feira às 09:00 | Telegram |

Tudo o que é para publicar à mão também fica no dashboard → **Publicar à mão** (legenda para copiar, ficheiros,
"Já publiquei"), mesmo sem Telegram.
